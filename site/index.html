AI-on-the-Edge – Gasmeter

Privater Test-Build auf Basis des offiziellen Releases v16.1.0. Es werden zwei Varianten angeboten, damit der Kameratakt isoliert verglichen und bei Bedarf zurückgesetzt werden kann.

Vor dem Flashen unbedingt beachten
  • SD-Karte vollständig sichern (insbesondere config.ini, ROIs, Modelle und Messhistorie).
  • Der Installer fragt nach einem vollständigen Löschen des ESP-Flashs. Für diesen Test bitte Erase/Full erase wählen, damit keine alte OTA-Auswahl die neue Firmware übersteuert.
  • Das Löschen betrifft den internen Flash des ESP32, nicht die microSD-Karte. Interne NVS-/OTA-Daten werden zurückgesetzt.
  • ESP32-CAM per USB anschließen. Falls nötig in den Bootloader-Modus wechseln (GPIO0/FLASH auf GND halten, Reset auslösen, danach FLASH loslassen).
  • Chrome oder Edge unter Windows verwenden. USB-Zugriff über Web Serial wird benötigt.

Test-Firmware: 8 MHz Kameratakt

Einzige Quellcodeänderung gegenüber v16.1.0: XCLK_FREQ_MHZ=8 statt des Standardwerts 20 MHz. Diese Variante dient ausschließlich dem WLAN-/Kamera-A/B-Test.

Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge verwenden.

Rückfall-Firmware: Original 20 MHz

Unveränderter Build des offiziellen AI-on-the-Edge-Releases v16.1.0. Damit kann der Test ohne erneute lokale Entwicklungsumgebung zurückgenommen werden.

Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge verwenden.

Nach dem Flashen

  1. ESP zurücksetzen und Start über die serielle Konsole beobachten.
  2. Prüfen, ob die Kamera initialisiert und ein Livebild erzeugt.
  3. Fünf Minuten Ping auf die ESP-IP laufen lassen und Paketverlust sowie maximale Antwortzeit notieren.
  4. Erst danach OCR und Messwertübernahme prüfen.
